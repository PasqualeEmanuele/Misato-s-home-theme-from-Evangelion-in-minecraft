# Misato-s-home-theme-from-Evangelion-in-minecraft
I recreated Misato's home theme in minecraft sinse (as far as i know) no one ever did it, the song is not made with noteblocks but with a datapack sinse i'm lazy

The "misato theme (EDITED).nbs" file is a music sheet for minecraft noteblocks that uses a third party software called "Note Block Studio" https://noteblock.studio/ https://github.com/OpenNBS/NoteBlockStudio all rights reservede, the song it self is heavely inspired by the one created by the user "catman0211" https://noteblock.world/song/ypqXlMTJVn

How to install

  Drop the zip's contents (the pack.mcmeta and data folder) into your world's saves/YourWorld/datapacks/misato_theme/.
  
  <img width="1142" height="227" alt="image" src="https://github.com/user-attachments/assets/9e055604-f36f-4f8a-a467-754aca735925" />
  
  In-game, run /reload.
  
  Run /function misato:start (from a command block or the chat/console).
  
  To stop it early: /function misato:stop.
